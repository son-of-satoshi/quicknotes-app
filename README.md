# QuickNotes App

QuickNotes is a clean, lightweight, and responsive note-taking web application designed to help users capture, categorize, search, and manage their thoughts instantly in the browser. Built as part of a web development curriculum project, it emphasizes semantic HTML, modern Flexbox layouts, modular JavaScript architecture, and robust local state persistence.

## Features
* **Categorized Notes**: Organize notes into **Personal**, **Work**, and **Study** categories with distinct visual indicators.
* **Live Validation**: Instant checks ensuring notes are neither empty nor exceed the 200-character limit.
* **Real-time Search**: Dynamically filter your saved notes instantly as you type, with a fallback message when no matches are found.
* **Data Persistence**: Automatically saves and loads your notes using browser `localStorage` so data survives page refreshes.
* **Responsive Design**: Adapts cleanly across devices, stacking controls gracefully on mobile screens.
